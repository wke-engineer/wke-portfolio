# 王可儿的个人主页 · Personal Portfolio（v2）

商丘师范学院 · 地理信息科学 · 大二在读。大学四年的成长档案：绩点 / 项目 / 实习 / 自媒体 / 志愿服务 / 竞赛 / 证书，并支持一键导出简历。

纯静态实现（HTML + CSS + 原生 JS），不需要安装任何依赖，双击 `index.html` 就能看。

## v2 新增功能

- **受众视角切换**：首屏可切换「完整版 / 求职 HR / 考研导师 / 留学考官」，切换后首屏简介、板块顺序、导出简历的板块重点都会跟着变（配置在 `data.js` 的 `audience` 字段）。
- **志愿服务板块**：三下乡社会实践等志愿服务经历。
- **页面内编辑**：点右上角 ✏️ 按钮，可直接在浏览器里修改全站文字内容；修改保存在浏览器 localStorage，点「导出 data.js」可下载修改后的文件永久保存。
- **项目可爱标识**：每个项目卡片带 emoji 标识与重要度徽章，项目直接链接 GitHub 仓库。

## 一、怎么改内容

**只改一个文件：`assets/js/data.js`**

打开它，里面每一块都有中文注释，把示例文字换成你的真实信息即可。保存后刷新浏览器就能看到效果。

| 数据字段 | 对应页面板块 |
| --- | --- |
| `profile` | 首屏（姓名、头衔、简介、联系方式） |
| `stats` | 首屏四张数字卡片 |
| `education` | 教育背景 + 绩点面板 |
| `internships` | 实习经历 |
| `projects` | 项目作品（自动生成类型筛选按钮） |
| `media` | 自媒体运营 |
| `awards` | 竞赛与荣誉 |
| `certificates` | 证书与资质 |
| `skills` | 技能栈（进度条） |
| `contactText` / `footerText` | 联系区文案 / 页脚 |

### 换成你自己的照片

1. 把照片放进 `assets/img/`，例如 `assets/img/me.jpg`
2. 在 `data.js` 里把 `avatar` 改成 `"assets/img/me.jpg"`

项目封面、证书扫描件同理：把图片放进 `assets/img/`，然后在对应的 `cover` 字段填路径。
**留空会自动生成一张好看的渐变占位图**，所以不用担心图片没准备好。

## 二、一键导出简历

页面上有三个入口（导航栏 / 首屏 / 底部）都能打开简历预览：

1. 点击「一键导出简历」→ 弹出 A4 简历预览（内容自动从 `data.js` 生成）
2. 点击「下载 / 打印 PDF」→ 在打印对话框里把目标选成「另存为 PDF」
3. 保存即可得到一份排版干净的 PDF 简历

> 打印时会自动隐藏网页本身，**只输出简历**，不需要手动调整。

底部还有个「导出数据备份」按钮，可以把所有数据导成 JSON 存起来。

## 三、其他功能

- **深浅色切换**：右上角太阳/月亮图标，选择会记在浏览器本地
- **项目筛选**：`projects` 里的 `type` 字段会自动生成筛选按钮

## 四、目录结构

```
.
├── index.html              # 页面结构
├── README.md
└── assets/
    ├── css/style.css       # 全部样式（主色在文件顶部 :root 里改）
    ├── js/
    │   ├── data.js         # ★ 唯一需要你改的文件
    │   └── app.js          # 渲染与交互逻辑
    └── img/
        ├── avatar.svg      # 默认头像占位
        └── favicon.svg     # 浏览器标签图标
```

想换主题色？打开 `assets/css/style.css`，改最上面 `:root` 里的
`--brand` 和 `--brand-rgb` 两个值就行（`--brand-rgb` 是同一个颜色的 RGB 写法）。
